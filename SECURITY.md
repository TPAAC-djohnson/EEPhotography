## Reporting a Vulnerability

We take the security of this project seriously and appreciate responsible disclosure of potential vulnerabilities.

How to Report

If you discover a security vulnerability, please do not disclose it publicly. Instead, report it privately by contacting the project maintainers through one of the following methods:

* Open a private security advisory (if supported by the repository hosting platform).
* Email the project maintainers at the designated security contact (for example, security@example.com).

Your report should include:

* A clear description of the vulnerability.
* Steps to reproduce the issue.
* The affected version(s).
* Any proof-of-concept code or screenshots, if applicable.
* Your contact information for follow-up questions.

What to Expect

After receiving your report, we will:

1. Acknowledge receipt within 3 business days.
2. Investigate and validate the reported issue.
3. Keep you informed of the investigation status at least once every 7 days until the issue is resolved or the report is closed.
4. Develop and test a fix if the vulnerability is confirmed.
5. Coordinate disclosure and release security updates before public announcement whenever possible.

If the Report Is Accepted

If the vulnerability is confirmed:

* A security fix will be prioritized.
* A patched release will be published for supported versions.
* Appropriate credit will be given to the reporter (unless anonymity is requested).

If the Report Is Declined

If the report is determined not to be a security vulnerability or cannot be reproduced, we will explain our reasoning and may request additional information if needed.

We appreciate the efforts of security researchers and the community in helping keep this project and its users safe.
