# ROOM SERVICE Archive

**Artist:** Darryl Johnson  
**Series:** ROOM SERVICE  
**Subtitle:** She Is Alone, But Never Off Stage  
**Location:** Atlanta, Georgia  
**Medium:** Photography

This repository folder archives the professional project system for **ROOM SERVICE**, including portfolio language, grant materials, exhibition planning, marketing rollout, website copy, asset organization, and administrative scripts.

## Purpose

ROOM SERVICE is a photographic series exploring the private emotional and psychological environments of Black women within intimate, domestic spaces. The work examines presence, performance, interiority, sensuality, and self-awareness through controlled lighting and close portraiture.

## Use

This archive is designed for:

- Grant submissions
- Gallery pitches
- Portfolio reviews
- Website development
- Exhibition planning
- Long-term project documentation
